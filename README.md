# Proyecto 28 · Portal del evento

Webapp inicial para invitados y administradores.

## Estado actual

- Invitación digital y datos del evento.
- Registro único de invitados por nombre en el navegador.
- Sugerencias y votación de canciones.
- Dedicatorias y contenido colaborativo.
- Panel visual de invitados, Caja, tareas, música y contenido.
- Acceso administrativo preparado para conectarse a un backend seguro.

Las credenciales no se guardan en este repositorio público. Para habilitar el acceso real de administradores se debe conectar una API con autenticación y base de datos.

## Ejecución local

```bash
python -m http.server 8765
```

Luego abrir `http://localhost:8765/`.
